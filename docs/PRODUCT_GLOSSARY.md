# Glossario di prodotto

- **Veraxis**: nome del prodotto e della piattaforma di Analytical Intelligence.
- **Skills Agent**: nome storico del repository; resta solo dove necessario per compatibilità tecnica.
- **Coordinator**: boundary di produzione che orchestra l'analisi end-to-end.
- **Veraxis Kernel**: runtime capability-oriented parallelo, non ancora boundary di produzione.
- **Knowledge Graph**: memoria governata di evidenze, relazioni e provenance.
- **Experience**: pattern analitici riutilizzabili, privi delle righe sorgente.
- **Quality Center**: vista operativa di benchmark, gate e readiness.

Nuova documentazione e testi UI devono usare “Veraxis” come nome prodotto e
“Skills Agent” soltanto per riferimenti storici o tecnici al repository.
